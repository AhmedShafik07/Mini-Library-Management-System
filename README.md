Mini Library Management System — Java

A Java Swing desktop application for managing a collection of books through a simple graphical user interface.

Features

* Display all available books
* Add new books
* Search for a specific book
* Remove books
* Count the total number of books
* Save book data to a text file
* Load saved book data when the application starts

Technologies & Concepts

* Java
* Java Swing
* Arrays
* File I/O
* Scanner
* PrintWriter
* Object-Oriented Programming

How to Run

Open the project in a Java IDE such as NetBeans and run LibraryGUI.java.

The application opens a graphical interface where users can manage the library’s book collection.
